Proposed community workflow

A better map starts with a source.

This sketch does not submit edits or open a live editor. A proposed production process would use public GitHub pull requests:

  1. Identify the organization precisely and include a public, attributable source.
  2. Propose a change to the future map data file. Separate an organizational relationship from a suggested introduction or shared interest.
  3. Include evidence for any confirmed relationship; maintainers review the pull request before publishing.

Nothing is sent or saved here. Do not include private contact information. An unlisted page would still be publicly accessible.
